# FindIt AI 🔎

An AI-powered campus Lost and Found application built using Python, Streamlit, SQLite, and Gemma 4.

## Features
- Report lost and found items
- Store reports using SQLite
- Use Gemma 4 to suggest possible item matches

## Tech Stack
- Python
- Streamlit
- SQLite
- Google Gemma 4 API

## Run Locally
1. Install dependencies: `pip install -r requirements.txt`
2. Add `GEMINI_API_KEY` to your local `.env` file.
3. Run: `streamlit run app.py`

Gemma 4 suggests possible matches; human verification is required.
